# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities privately — do not open a public issue.

- Use GitHub's [private vulnerability reporting](https://github.com/devletes/filament-time-picker/security/advisories/new)
- Or email [packages@devletes.com](mailto:packages@devletes.com)

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce, or a proof of concept
- The package version and your PHP / Laravel / Filament versions

We will acknowledge your report within 72 hours and keep you updated as we work on a fix.
